1. Lambda 表达式

Lambda = 匿名函数，让 Java 也能"函数式编程"。

JavaScript 
// 箭头函数
const add = (a, b) => a + b;
const greet = name => `Hello, ${name}`;
const print = () => console.log("hi");
Java 
// 完整语法：(参数) -> { 方法体 }
BinaryOperator<Integer> add = (a, b) -> a + b;
Consumer<String> greet = name -> System.out.println("Hello, " + name);
Runnable print = () -> System.out.println("hi");

// 单参数可省略括号
Function<String, Integer> strLen = s -> s.length();

// 单语句可省略 return
Supplier<String> hello = () -> "hello";

2. 函数式接口

函数式接口 = 只有一个抽象方法的接口。Lambda 实际上就是这种接口的实例。

接口抽象方法用途JS 对比
Runnablevoid run()无参无返回() => {}
Supplier<T>T get()无参有返回（生产）() => x
Consumer<T>void accept(T)有参无返回（消费）x => {}
Function<T,R>R apply(T)有参有返回（转换）x => y
Predicate<T>boolean test(T)判断x => bool
BiFunction<T,U,R>R apply(T, U)两参有返回(a, b) => c

3. 方法引用 ::

方法引用 = 更简洁的 Lambda，当你只是"传入一个已存在的方法"。

// 静态方法引用
Function<String, Integer> parser = Integer::parseInt;
int n = parser.apply("123");  // 123

// 实例方法引用
String str = "hello";
Supplier<Integer> len = str::length;

// 构造方法引用
Supplier<ArrayList<String>> listFactory = ArrayList::new;
Function<Integer, ArrayList<String>> sizedList = ArrayList::new;

// System.out::println 是经典用法
list.forEach(System.out::println);  // 类似 list.forEach(console.log)

4. Stream 进阶

List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "David");

// findFirst
Optional<String> first = names.stream()
    .filter(n -> n.startsWith("C"))
    .findFirst();
first.ifPresent(System.out::println);  // Charlie

// anyMatch / allMatch / noneMatch
boolean hasAlice = names.stream().anyMatch(n -> n.equals("Alice"));  // true
boolean allLong  = names.stream().allMatch(n -> n.length() > 2);     // true

// joining
String joined = names.stream().collect(Collectors.joining(", "));
// "Alice, Bob, Charlie, David"

// groupingBy
Map<Integer, List<String>> byLen = names.stream()
    .collect(Collectors.groupingBy(String::length));
// {3=[Bob], 5=[Alice, David], 7=[Charlie]}

// mapToInt 求统计
IntSummaryStatistics stats = names.stream()
    .collect(Collectors.summarizingInt(String::length));
// count=4, sum=19, min=3, avg=4.75, max=7

5. Optional - 优雅处理 null

类似 JS 的 obj?.prop 可选链。

// JS
const name = user?.profile?.name ?? "Anonymous";

// Java 8+
String name = Optional.ofNullable(user)
    .map(User::getProfile)
    .map(Profile::getName)
    .orElse("Anonymous");
避免在 Stream 里修改外部状态
Stream 设计是"无副作用"的。在 lambda 里修改外部变量会引发并发问题，Java 直接禁了（需要 final 或等效 final）。
