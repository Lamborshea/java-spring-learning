# L20: 缓存

> @Cacheable、Redis、Caffeine

## 本节课目标

- 理解 Spring Cache 抽象
- 掌握 @Cacheable、@CacheEvict、@CachePut
- 学会使用 Caffeine 本地缓存
- 了解 Redis 分布式缓存

## 核心概念

### 1. Spring Cache 注解

| 注解 | 说明 | JS对比 |
|------|------|--------|
| @Cacheable | 查询时缓存 | 类似 memoize |
| @CachePut | 更新时刷新缓存 | 类似 cache.set |
| @CacheEvict | 删除缓存 | 类似 cache.delete |
| @Caching | 组合多个缓存操作 | 组合操作 |

### 2. 缓存策略

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   请求       │────>│  缓存命中？  │────>│  返回缓存   │
└─────────────┘     └─────────────┘     └─────────────┘
                           │
                           │ 否
                           ▼
                    ┌─────────────┐
                    │  查询数据库  │
                    └─────────────┘
                           │
                           ▼
                    ┌─────────────┐
                    │  存入缓存    │
                    └─────────────┘
```

### 3. 缓存失效场景

- 数据过期（TTL）
- 数据更新（主动删除）
- 容量满（LRU淘汰）
