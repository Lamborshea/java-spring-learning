L03 面向对象编程（OOP）

⏱ 2.5 小时 📦 Java 基础 🎯 核心概念
对前端工程师的 OOP
JavaScript 的 ES6 class 写法和 Java class 看起来很像，但底层和语义差别很大。Java 的 OOP 是真正的、严格的、强制的面向对象。

本节目标

  • 掌握类、对象、构造方法
  • 理解封装、继承、多态
  • 会用接口和抽象类

1. 类与对象

JavaScript 
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
  greet() {
    return `Hello, I'm ${this.name}`;
  }
}

const john = new Person("John", 25);
console.log(john.greet());
Java 
public class Person {
  // 字段（属性）—— 私有
  private String name;
  private int age;

  // 构造方法
  public Person(String name, int age) {
    this.name = name;
    this.age = age;
  }

  // 方法
  public String greet() {
    return "Hello, I'm " + this.name;
  }

  // Getter / Setter
  public String getName() { return name; }
  public void setName(String name) { this.name = name; }
}

Person john = new Person("John", 25);
System.out.println(john.greet());

2. 三大特性：封装

封装 = 把数据藏起来，让外部必须通过方法访问。

public class BankAccount {
  private double balance;  // 私有：外部不能直接访问

  public void deposit(double amount) {
    if (amount <= 0) {
      throw new IllegalArgumentException("金额必须 > 0");
    }
    this.balance += amount;  // 在方法里加校验逻辑
  }

  public double getBalance() {
    return balance;
  }
}

为什么？类比：前端不会把组件内部 state 直接暴露给全局，必须通过 props/events。

3. 三大特性：继承

// 父类
public class Animal {
  protected String name;  // protected：子类可访问

  public Animal(String name) {
    this.name = name;
  }

  public void speak() {
    System.out.println("...");
  }
}

// 子类
public class Dog extends Animal {
  public Dog(String name) {
    super(name);  // 必须显式调用父类构造
  }

  @Override  // 注解：标记重写父类方法
  public void speak() {
    System.out.println(name + " says: Woof!");
  }
}
Java 单继承
Java 类只能 extends 一个父类（不像 C++ 多继承）。想"多重继承"用接口。

4. 三大特性：多态

多态 = 父类引用指向子类对象，方法调用看实际类型。

Animal animal = new Dog("Buddy");
animal.speak();  // 输出 "Buddy says: Woof!"
// 编译看 Animal，运行看 Dog

// 好处：写通用代码
public void makeSpeak(Animal animal) {
  animal.speak();  // 不用关心具体类型
}

makeSpeak(new Dog("A"));  // "A says: Woof!"
makeSpeak(new Cat("B"));  // "B says: Meow!"

5. 抽象类 vs 接口

特性抽象类接口
关键字abstract classinterface
方法实现可有可无JDK 8+ 可有 default
字段可有实例字段只能是常量（public static final）
继承数量单继承多实现
构造方法可有不能有
使用场景有共同行为 + 共同状态纯粹定义"能力"
 
// 接口：定义"能做什么"
public interface Drawable {
  void draw();  // 抽象方法（默认 public abstract）

  // JDK 8+ default 方法
  default void print() {
    System.out.println("Printing...");
  }

  // JDK 8+ static 方法
  static Drawable createCircle() {
    return new Circle();
  }
}

// 实现
public class Circle implements Drawable {
  @Override
  public void draw() {
    System.out.println("Drawing circle");
  }
}

// 多实现
public class Button implements Drawable, Clickable {
  // ...
}

6. 实战：一个完整例子

// 抽象类：所有"形状"有共同特性
abstract class Shape {
  protected String color;

  public Shape(String color) {
    this.color = color;
  }

  // 抽象方法：子类必须实现
  public abstract double area();

  public void describe() {
    System.out.println(color + " shape, area = " + area());
  }
}

class Rectangle extends Shape {
  private double width, height;

  public Rectangle(String color, double w, double h) {
    super(color);
    this.width = w;
    this.height = h;
  }

  @Override
  public double area() {
    return width * height;
  }
}

class Circle extends Shape {
  private double radius;

  public Circle(String color, double r) {
    super(color);
    this.radius = r;
  }

  @Override
  public double area() {
    return Math.PI * radius * radius;
  }
}

// 使用多态
public static void main(String[] args) {
  Shape[] shapes = { new Rectangle("red", 2, 3), new Circle("blue", 5) };
  for (Shape s : shapes) {
    s.describe();  // 多态调用
  }
}
