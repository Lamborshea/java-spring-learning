L22 API 文档自动生成

⏱ 1 小时 📦 进阶功能 🎯 SpringDoc + Knife4j
为什么需要自动文档？

手写 API 文档 → 接口改了就忘了改文档 → 文档过时 → 没人信。
自动文档：注解即文档，代码改文档自动更新。

本节目标

  • 会用 SpringDoc / OpenAPI 3
  • 会用 Knife4j 增强 UI
  • 理解 API 版本管理

1. 引入依赖

<dependency>
  <groupId>org.springdoc</groupId>
  <artifactId>springdoc-openapi-starter-webmvc-ui</artifactId>
  <version>2.5.0</version>
</dependency>
<!-- 国内推荐用 Knife4j -->
<dependency>
  <groupId>com.github.xiaoymin</groupId>
  <artifactId>knife4j-openapi3-jakarta-spring-boot-starter</artifactId>
  <version>4.5.0</version>
</dependency>

2. 基础配置

@Configuration
public class OpenApiConfig {

  @Bean
  public OpenAPI customOpenAPI() {
    return new OpenAPI()
      .info(new Info()
        .title("任务管理 API")
        .version("1.0.0")
        .description("任务管理系统的 RESTful API 文档")
        .contact(new Contact().name("Lambor").email("lambor@example.com"))
      )
      .addSecurityItem(new SecurityRequirement().addList("bearerAuth"))
      .components(new Components()
        .addSecuritySchemes("bearerAuth",
          new SecurityScheme()
            .type(SecurityScheme.Type.HTTP)
            .scheme("bearer")
            .bearerFormat("JWT")
        )
      );
  }
}

3. Controller 注解

@RestController
@RequestMapping("/api/users")
@Tag(name = "用户管理", description = "用户的 CRUD 接口")
public class UserController {

  @Operation(summary = "获取用户列表", description = "分页查询用户")
  @GetMapping
  public ApiResponse<Page<User>> list(
      @Parameter(description = "页码", example = "0")
      @RequestParam(defaultValue = "0") int page,

      @Parameter(description = "每页大小", example = "10")
      @RequestParam(defaultValue = "10") int size
  ) {
    return ApiResponse.success(userService.findPage(page, size));
  }

  @Operation(summary = "创建用户")
  @ApiResponses({
    @ApiResponse(responseCode = "201", description = "创建成功"),
    @ApiResponse(responseCode = "400", description = "参数错误")
  })
  @PostMapping
  public ApiResponse<User> create(
      @RequestBody @Valid CreateUserRequest req
  ) {
    return ApiResponse.success(userService.create(req));
  }
}

4. DTO 注解

@Schema(description = "创建用户请求")
public record CreateUserRequest(
    @Schema(description = "用户名", example = "lambor", requiredMode = RequiredMode.REQUIRED)
    @NotBlank String username,

    @Schema(description = "邮箱", example = "lambor@example.com")
    @Email String email,

    @Schema(description = "年龄", example = "25")
    @Min(0) Integer age
) {}

6. API 版本管理

方式 1：URL 路径版本
  /api/v1/users
  /api/v2/users

方式 2：请求头版本
  Accept: application/vnd.myapi.v2+json

方式 3：参数版本
  /api/users?version=2

推荐方式 1（最直观）：

@RestController
@RequestMapping("/api/v1/users")
public class UserControllerV1 { ... }

@RestController
@RequestMapping("/api/v2/users")
public class UserControllerV2 { ... }

7. 生产实践

建议
  • 所有 Controller 和 DTO 都加 @Tag / @Schema
  • 用 @ExampleObject 提供示例
  • 生产环境可以关闭 / 限制访问 Swagger UI
  • 用 Knife4j 可以有更好的 UI 和调试体验
练习 1： 在 spring-boot-webapp 加 springdoc-openapi 依赖，启动访问 /swagger-ui.html

练习 2： 给 UserController 加 @Tag、@Operation 注解

练习 3： 给 DTO 加 @Schema，看文档中的字段说明变化
