1. Spring Boot 是什么？

Spring 是 Java 生态最老牌的应用框架，但早期 Spring 配置极其繁琐（大量 XML）。

Spring Boot 的使命：让 Spring 变得"开箱即用"。

  • 自动配置（Auto-Configuration）：根据 classpath 里的依赖，自动配好一切
  • 内嵌服务器：自带 Tomcat / Jetty，java -jar 直接跑
  • Starter 依赖：一组相关依赖打包成 spring-boot-starter-*
  • 约定优于配置：标准的目录结构、配置文件命名

5. 关键注解

@SpringBootApplication  // = @Configuration + @EnableAutoConfiguration + @ComponentScan
@SpringBootApplication
public class HelloSpringBootApplication {

    public static void main(String[] args) {
        SpringApplication.run(HelloSpringBootApplication.class, args);
    }
}

@RestController  // = @Controller + @ResponseBody，返回 JSON 而非页面
@RequestMapping("/api/demo")
public class DemoController {

    @GetMapping("/hello")  // 处理 GET /api/demo/hello
    public String hello() {
        return "Hello, Spring Boot!";
    }
}
注解作用
@SpringBootApplication主类标记，启用自动配置
@RestControllerREST 控制器，返回数据而非页面
@GetMapping处理 GET 请求
@PostMapping处理 POST 请求
@RequestMapping通用路径映射

6. 启动流程（理解用）

1. JVM 启动，执行 main()
2. SpringApplication.run() 创建 Spring 上下文
3. 扫描 @ComponentScan 范围内的组件
4. 应用所有自动配置（@EnableAutoConfiguration）
5. 启动内嵌 Tomcat
6. 监听 8080 端口
7. 应用就绪
对比前端
类似 new Vue({...}).$mount('#app')：
  1. 创建 Vue 实例
  2. 扫描 components、注册路由
  3. 应用全局配置
  4. 挂载到 DOM
  5. 应用就绪

7. 运行

cd L06-spring-boot-intro
mvn spring-boot:run

改了代码没生效：默认 dev 工具不开启，要重启。L09 会讲热部署。
