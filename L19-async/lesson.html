L19 异步编程

⏱ 1.5 小时 📦 进阶功能 🎯 @Async + CompletableFuture
为什么要异步？

同步：用户下单 → 创建订单 → 扣库存 → 发邮件（5 秒，用户等不了）
异步：用户下单 → 创建订单 → 扣库存 → 立即返回（0.5 秒），发邮件后台慢慢发

本节目标

  • 理解同步 vs 异步
  • 会用 @Async 注解
  • 会用 CompletableFuture
  • 配置线程池

1. 同步 vs 异步

JavaScript 
// 同步
const result = fetchData();
use(result);  // 等

// 异步
fetchData().then(result => use(result));

// async/await
const result = await fetchData();
use(result);
Java 
// 同步
String result = fetchData();
use(result);  // 等

// 异步（CompletableFuture）
CompletableFuture<String> future =
    CompletableFuture.supplyAsync(() -> fetchData());
future.thenAccept(result -> use(result));

// 多任务并行
CompletableFuture.allOf(f1, f2, f3)
    .thenRun(() -> done());

2. @Async 入门

@SpringBootApplication
@EnableAsync  // 启用异步
public class App { ... }

@Service
public class EmailService {

  @Async  // 异步执行
  public void sendEmail(String to, String content) {
    // 耗时的发邮件
    try { Thread.sleep(2000); } catch (Exception e) {}
    System.out.println("邮件已发送到 " + to);
  }
}

@RestController
public class OrderController {
  @Autowired
  private EmailService emailService;

  @PostMapping("/order")
  public String create() {
    emailService.sendEmail("user@example.com", "订单创建");  // 不等待
    return "订单创建成功";  // 立即返回
  }
}

3. 线程池配置

spring:
  task:
    execution:
      pool:
        core-size: 4        # 核心线程
        max-size: 16        # 最大线程
        queue-capacity: 100 # 队列容量
        thread-name-prefix: async-

或自定义：

@Configuration
public class AsyncConfig {

  @Bean("taskExecutor")
  public Executor taskExecutor() {
    ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
    executor.setCorePoolSize(4);
    executor.setMaxPoolSize(16);
    executor.setQueueCapacity(100);
    executor.setThreadNamePrefix("async-");
    executor.initialize();
    return executor;
  }
}

@Async("taskExecutor")
public void method() { ... }

4. CompletableFuture

// 单个异步
CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
  // 耗时操作
  return "result";
});

future.thenAccept(result -> System.out.println(result));

// 并行执行多个
CompletableFuture<User> f1 = CompletableFuture.supplyAsync(() -> userService.findById(1L));
CompletableFuture<List<Order>> f2 = CompletableFuture.supplyAsync(() -> orderService.findByUser(1L));

CompletableFuture.allOf(f1, f2).join();  // 等全部完成

// 任一完成
CompletableFuture.anyOf(f1, f2).join();

// 链式转换
CompletableFuture<String> f = CompletableFuture
    .supplyAsync(() -> "hello")
    .thenApply(s -> s + " world")
    .thenApply(String::toUpperCase);
// "HELLO WORLD"

5. 异常处理

CompletableFuture<String> f = CompletableFuture
    .supplyAsync(() -> {
      if (true) throw new RuntimeException("err");
      return "ok";
    })
    .exceptionally(ex -> "fallback: " + ex.getMessage());

// 或者用 handle
CompletableFuture<String> f2 = CompletableFuture
    .supplyAsync(() -> "data")
    .handle((result, ex) -> ex != null ? "err" : result);
常见坑
  • @Async 方法必须 public，且同类内调用无效
  • 异步方法不能返回 void 给调用方传递异常
  • 线程池满了要排队，配置合理
