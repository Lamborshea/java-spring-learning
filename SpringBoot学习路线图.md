### ⚠️ 可行性评估

3 个月从零 Java 到独立开发 Spring Boot 项目，时间**偏紧但可行**，原因：
- 你有前端编程经验，理解变量/函数/循环/数据结构/HTTP 等概念，不需要从零学编程
- Java 语法与 JS/TS 有相似性，可加速学习
- 但 Java 的类型系统、OOP 范式、JVM 生态与前端差异大，不能跳过

**风险点**：若 Week 1-4 Java 基础阶段进度落后超过 1 周，建议将总周期延长至 4 个月，不要压缩 Spring Boot 阶段。

## 成功标准

完成本路线图后，应能：

1. **掌握 Java 核心语法**，能独立编写面向对象程序，理解集合框架、异常处理、IO 基础
2. **独立搭建** Spring Boot 项目，设计并实现 RESTful API（含参数校验、统一响应格式）
3. **操作数据库**：使用 JPA 或 MyBatis 完成 CRUD 及关联查询，理解事务管理
4. **实现鉴权并交付项目**：基于 JWT 完成用户认证，独立交付一个可 Docker 部署的后端项目

## 常见卡点

| 卡点                                       | 解决方案                                                                 |
| ------------------------------------------ | ------------------------------------------------------------------------ |
| Java 强类型不适应，总想写成 JS 风格         | 刻意练习声明类型，理解编译期检查是 Java 的优势不是负担                     |
| OOP 思维转换困难                           | 类比前端：class 类 = JS 的 class（ES6），但 Java 更严格；多写继承/接口示例 |
| 集合类型太多不知道选哪个                   | 记住：List 有序可重复（用 ArrayList）、Set 无序不重复、Map 键值对（用 HashMap） |
| Stream API 概念陌生                        | 类比 JS：filter = Array.filter，map = Array.map，reduce = Array.reduce    |
| IoC/DI 概念抽象                            | 类比前端：Vue 的 provide/inject、React 的 Context，本质都是"别人帮你创建对象" |
| 注解太多记不住                             | 做一份注解速查表（按功能分类），用的过程中自然记住                        |
| JPA 关联关系映射容易绕晕                   | 先画 ER 图，再写代码；先掌握 @ManyToOne，再逐步加其他关系                  |
| Spring Security 过滤器链概念复杂           | 在过滤器中打断点，跟一遍请求流程；先跑通默认配置再自定义                    |
| 不知道项目结构怎么组织                     | 采用标准分层：controller → service → repository → entity                   |
| Maven 依赖下载慢                           | 配置阿里云镜像（settings.xml）                                            |
| 从 Java 基础到 Spring Boot 跨度大          | Week 5 前先跑通一个最简单的 Spring Boot Hello World，建立信心               |

## Java vs JavaScript 语法对照速查

| 概念             | JavaScript                          | Java                                          |
| ---------------- | ----------------------------------- | --------------------------------------------- |
| 变量声明         | `let x = 1`                         | `int x = 1;`（必须声明类型，必须有分号）       |
| 字符串           | `'hello'` / `"hello"`              | `"hello"`（双引号，单引号是 char）             |
| 数组             | `let arr = [1, 2, 3]`              | `int[] arr = {1, 2, 3};` 或 `List<Integer>`   |
| 对象             | `{ name: 'Tom', age: 20 }`         | `class Person { String name; int age; }`       |
| 函数             | `function add(a, b) { return a+b }` | `int add(int a, int b) { return a+b; }`       |
| 箭头函数         | `(x) => x * 2`                     | `x -> x * 2`（Lambda，需要函数式接口）          |
| 数组遍历         | `arr.forEach(x => console.log(x))` | `arr.forEach(x -> System.out.println(x))`     |
| 数组过滤         | `arr.filter(x => x > 0)`           | `arr.stream().filter(x -> x > 0).collect(...)` |
| 类定义           | `class Dog extends Animal {}`      | `class Dog extends Animal {}`（类似但有区别）   |
| 接口             | 无（TS 有 interface）              | `interface Runnable { void run(); }`           |
| 导入模块         | `import { x } from './mod'`        | `import com.example.Mod;`                      |
| 包管理           | npm / yarn                          | Maven / Gradle                                |
| 异步             | `async/await` / Promise            | 多线程 / CompletableFuture                     |
| 空值             | `null` / `undefined`               | `null`（无 undefined）                         |
| 类型检查         | 运行时（动态类型）                   | 编译时（静态类型）                              |
