L12 请求参数处理

⏱ 1.5 小时 📦 Web 开发 🎯 四种参数绑定

本节目标

  • 掌握 @PathVariable（路径参数）
  • 掌握 @RequestParam（查询参数）
  • 掌握 @RequestBody（请求体）
  • 掌握 @RequestHeader（请求头）

1. 四种参数

注解位置示例
@PathVariableURL 路径/users/{id}
@RequestParamQuery String/users?name=Tom
@RequestBody请求体（JSON）POST/PUT 的 body
@RequestHeader请求头Authorization: Bearer xxx

2. @PathVariable 路径参数

// GET /api/users/123
@GetMapping("/users/{id}")
public User getUser(@PathVariable Long id) {
  return userService.findById(id);
}

// 多个路径参数
// GET /api/users/123/orders/456
@GetMapping("/users/{userId}/orders/{orderId}")
public Order getOrder(
    @PathVariable Long userId,
    @PathVariable Long orderId
) { ... }

3. @RequestParam 查询参数

// GET /api/users?page=0&size=10&keyword=Tom
@GetMapping("/users")
public List<User> list(
    @RequestParam(defaultValue = "0") int page,
    @RequestParam(defaultValue = "10") int size,
    @RequestParam(required = false) String keyword
) {
  return userService.search(page, size, keyword);
}

注意：基本类型默认 required = true，要可选必须加 required = false 或用包装类 Integer。

4. @RequestBody 请求体

// POST /api/users
// Content-Type: application/json
// {"name": "Tom", "email": "tom@example.com"}
@PostMapping("/users")
public User create(@RequestBody CreateUserRequest req) {
  return userService.create(req);
}

public record CreateUserRequest(
    @NotBlank String name,
    @Email String email,
    @Min(0) int age
) {}
DTO 设计

不要直接用 Entity 接收请求体！
Entity 是数据库映射，DTO 是 API 入参，分开能避免：

  • 接口字段泄露数据库结构
  • 字段校验和持久化逻辑混淆
  • API 演进时影响数据库

5. @RequestHeader 请求头

@PostMapping("/users")
public User create(
    @RequestHeader("Authorization") String token,  // 必填
    @RequestHeader(value = "X-Trace-Id", required = false) String traceId,
    @RequestBody CreateUserRequest req
) { ... }

6. 综合示例

@RestController
@RequestMapping("/api/users")
public class UserController {

  @GetMapping
  public List<User> list(
      @RequestParam(defaultValue = "0") int page,
      @RequestParam(defaultValue = "10") int size
  ) {
    return userService.findPage(page, size);
  }

  @GetMapping("/{id}")
  public User get(@PathVariable Long id) {
    return userService.findById(id);
  }

  @PostMapping
  @ResponseStatus(HttpStatus.CREATED)
  public User create(@RequestBody @Valid CreateUserRequest req) {
    return userService.create(req);
  }

  @PutMapping("/{id}")
  public User update(
      @PathVariable Long id,
      @RequestBody @Valid UpdateUserRequest req
  ) {
    return userService.update(id, req);
  }

  @DeleteMapping("/{id}")
  @ResponseStatus(HttpStatus.NO_CONTENT)
  public void delete(@PathVariable Long id) {
    userService.delete(id);
  }
}

7. JS 对照

JavaScript (Express) 
app.get('/users/:id', (req, res) => {
  const id = req.params.id;        // 路径参数
  const keyword = req.query.kw;    // 查询参数
});

app.post('/users', (req, res) => {
  const body = req.body;           // 请求体
  const auth = req.headers.authorization; // 请求头
});
Java (Spring) 
@GetMapping("/users/{id}")
public User get(

@PostMapping("/users")
