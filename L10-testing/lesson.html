L10 单元测试

⏱ 2 小时 📦 Spring Boot 核心 🎯 JUnit 5 + Mockito

本节目标

  • 掌握 JUnit 5 注解
  • 会用 Mockito 模拟对象
  • 会用 @SpringBootTest 集成测试

1. JUnit 5 注解

注解作用
@Test标记测试方法
@BeforeEach每个测试方法前执行
@AfterEach每个测试方法后执行
@BeforeAll所有测试前执行（static）
@Disabled禁用测试
@DisplayName自定义测试名

2. 基础测试

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class UserServiceTest {

  @Test
  @DisplayName("创建用户应该成功")
  void testCreateUser() {
    UserService service = new UserService();
    User user = service.createUser("Lambor", "lambor@example.com");
    assertNotNull(user);
    assertEquals("Lambor", user.getName());
  }

  @Test
  void testException() {
    assertThrows(IllegalArgumentException.class, () -> {
      // 应该抛异常的代码
    });
  }
}

4. Mockito 模拟

为什么要 mock？单元测试只测当前类，不应该连数据库、HTTP。

import static org.mockito.Mockito.*;

@ExtendWith(MockitoExtension.class)
class UserServiceTest {

  @Mock  // 创建一个假的 UserRepository
  private UserRepository userRepository;

  @InjectMocks  // 自动把 mock 注入到 UserService
  private UserService userService;

  @Test
  void testGetUser() {
    // 设定假行为
    when(userRepository.findById(1L))
        .thenReturn(Optional.of(new User("Lambor")));

    // 调用真实方法
    User user = userService.getUser(1L);

    // 断言
    assertEquals("Lambor", user.getName());

    // 验证方法被调用
    verify(userRepository, times(1)).findById(1L);
  }
}

5. Spring Boot 集成测试

@SpringBootTest  // 启动整个 Spring 上下文
class WebIntegrationTest {

  @Autowired
  private TestRestTemplate restTemplate;

  @Test
  void testGetUsers() {
    ResponseEntity<List> response = restTemplate.getForEntity(
        "/api/users", List.class
    );
    assertEquals(200, response.getStatusCode().value());
  }
}

// 只测 Web 层（更快）
@WebMvcTest(UserController.class)
class UserControllerTest {
  @Autowired
  private MockMvc mockMvc;

  @Test
  void testList() throws Exception {
    mockMvc.perform(get("/api/users"))
        .andExpect(status().isOk());
  }
}
