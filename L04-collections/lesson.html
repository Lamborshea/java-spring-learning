1. 集合体系总览

Java 集合的核心是 Collection 和 Map 两大接口：

                Collection
                /        \
             List        Set
            /    \        |
    ArrayList  LinkedList  HashSet
                             |
                          TreeSet (有序)

           Map (独立)
            /     \
        HashMap   TreeMap
         |
      LinkedHashMap (有序)

2. List：有序可重复

JavaScript 
const arr = [1, 2, 3];
arr.push(4);
arr.pop();
arr.includes(2);  // true
arr.map(x => x * 2);
arr.filter(x => x > 1);
Java 
// ArrayList：底层数组，查询快，增删慢
List list = new ArrayList<>();
list.add(1);
list.add(2);
list.add(3);
list.remove(2);           // 按索引删除
list.contains(2);         // 类似 includes
list.get(0);              // 按索引访问

// LinkedList：底层链表，增删快，查询慢
List linked = new LinkedList<>();
选哪个？
99% 场景用 ArrayList，除非频繁在中间增删才用 LinkedList。

3. Set：无序不可重复

JavaScript 
const set = new Set([1, 2, 3, 2, 1]);
console.log(set);  // Set { 1, 2, 3 }
set.add(4);
set.has(2);        // true
Java 
Set set = new HashSet<>();
set.add(1);
set.add(2);
set.add(2);        // 加不进去
set.contains(2);   // true
set.size();        // 2

// 元素必须实现 hashCode() 和 equals()

4. Map：键值对

JavaScript 
const obj = { name: "John", age: 25 };
const map = new Map();
map.set("name", "John");
map.get("name");
map.has("name");
map.delete("age");
Object.keys(obj);
Java 
// HashMap：最常用
Map map = new HashMap<>();
map.put("name", "John");
map.put("age", 25);

map.get("name");
map.getOrDefault("x", 0);  // 不存在则返回默认值
map.containsKey("name");
map.remove("age");

// 遍历
map.forEach((k, v) -> System.out.println(k + "=" + v));

5. 泛型 <T>

泛型 = 类型参数化，让集合/类支持多种类型且保证类型安全。

// 不带泛型（Java 早期代码）
List list = new ArrayList();
list.add("hello");
list.add(123);
String s = (String) list.get(0);  // 要强转，运行时才报错

// 带泛型（推荐）
List<String> list = new ArrayList<>();
list.add("hello");
String s = list.get(0);  // 不需要强转，编译时就保证

// 自定义泛型类
public class Box<T> {
  private T content;
  public void set(T content) { this.content = content; }
  public T get() { return content; }
}

Box<String> stringBox = new Box<>();
stringBox.set("hi");
String s = stringBox.get();

6. Stream API（重点）

Stream 是 Java 8 引入的函数式数据处理流水线。类似 JS 数组方法链。

List<Integer> nums = Arrays.asList(1, 2, 3, 4, 5, 6);

// 过滤偶数 → 乘以 2 → 求和
int sum = nums.stream()
    .filter(n -> n % 2 == 0)        // 保留偶数
    .map(n -> n * 2)                // 翻倍
    .reduce(0, Integer::sum);       // 求和
// = (2*2 + 4*2 + 6*2) = 24

// 收集为 List
List<Integer> result = nums.stream()
    .filter(n -> n > 3)
    .collect(Collectors.toList());

// 转 Map
Map<Integer, String> map = nums.stream()
    .collect(Collectors.toMap(
        n -> n,
        n -> "num=" + n
    ));

// 分组
Map<Boolean, List<Integer>> groups = nums.stream()
    .collect(Collectors.partitioningBy(n -> n % 2 == 0));
// {false=[1,3,5], true=[2,4,6]}
