1. 基本数据类型（Primitive Types）

Java 有 8 个基本类型，不是对象，存的是值本身。

分类类型大小JS 对比
整数byte1 字节无对应
整数short2 字节无对应
整数int4 字节number
整数long8 字节BigInt
浮点float4 字节number
浮点double8 字节number
字符char2 字节无单字符类型
布尔boolean1 位boolean
JavaScript 
// 只有 number 和 bigint
let a = 1;
let b = 3.14;
let big = 12345678901234567890n;

// 弱类型可以混
let x = 1;
x = "hello";  // OK
Java 
// 必须明确类型
int a = 1;          // 默认整数
double b = 3.14;    // 默认浮点
long big = 123456789012345L;  // 末尾 L
float f = 3.14f;    // 末尾 f
char c = 'A';       // 单引号
boolean flag = true;

// 强类型
int x = 1;
// x = "hello";  // 编译错误！

2. 变量与常量

JavaScript 
// 三种声明方式
var old = "过时";
let count = 10;       // 块级
const PI = 3.14;      // 常量

// const 是引用不可变
const obj = {};
obj.name = "ok";  // 可以！
obj = {};  // 错误！
Java 
// 变量
int age = 25;
String name = "John";

// 常量：final 修饰
final double PI = 3.14159;
// PI = 3.14;  // 编译错误！

// 命名规范：全大写下划线
final int MAX_COUNT = 100;
final String DEFAULT_NAME = "Guest";

3. 字符串

JavaScript 
const name = "John";

// 模板字符串（最方便）
const msg = `Hello, ${name}!`;

// 常用方法
name.toUpperCase();   // "JOHN"
name.includes("o");   // true
name.substring(0, 2); // "Jo"
Java 
String name = "John";

// 只能拼接
String msg = "Hello, " + name + "!";

// 格式化
String msg2 = String.format("Hello, %s!", name);

// 常用方法
name.toUpperCase();    // "JOHN"
name.contains("o");    // true
name.substring(0, 2);  // "Jo"

// JDK 15+ 文本块
String sql = """
    SELECT * FROM users
    WHERE id = 1
    """;
⚠️ String 不可变

Java 的 String 是不可变对象，每次"修改"其实创建了新对象。大量拼接用 StringBuilder：

// ❌ 慢
String s = "";
for (int i = 0; i < 1000; i++) {
    s = s + i;
}

// ✅ 快
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
String s = sb.toString();

4. == vs .equals()

这是 Java 面试必考题，也是新手最容易踩的坑。

JavaScript 
// == 触发类型转换
1 == "1"        // true ⚠️

// === 严格比较
1 === "1"       // false
[1] === [1]     // false（引用不同）

// 对象的相等判断
JSON.stringify(a) === JSON.stringify(b)
Java 
// == 对基本类型比较值
int a = 1;
int b = 1;
a == b;  // true

// == 对对象比较引用地址！
String s1 = new String("hi");
String s2 = new String("hi");
s1 == s2;        // false（不同对象）

// ✅ 比较内容用 .equals()
s1.equals(s2);   // true

6. 控制流

// if-else 同 JS
if (age >= 18) {
    System.out.println("成年");
} else if (age >= 12) {
    System.out.println("青少年");
} else {
    System.out.println("儿童");
}

// switch 表达式（Java 14+，推荐）
String day = "MONDAY";
String type = switch (day) {
    case "MONDAY", "TUESDAY", "WEDNESDAY", "THURSDAY", "FRIDAY" -> "工作日";
    case "SATURDAY", "SUNDAY" -> "周末";
    default -> "无效";
};

// for 循环
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}

// 增强 for（类似 for...of）
String[] names = {"Alice", "Bob", "Charlie"};
for (String name : names) {
    System.out.println(name);
}

7. 类型转换

// 自动转：小 → 大
byte b = 10;
int i = b;       // byte → int OK
double d = i;    // int → double OK

// 强制转：大 → 小（可能丢精度）
double d = 3.14;
int i = (int) d;  // 3，丢小数

// 字符串 ↔ 数字
String s = "123";
int n = Integer.parseInt(s);   // 字符串 → int
String back = String.valueOf(n); // int → 字符串
