L15 参数校验

⏱ 1.5 小时 📦 Web 开发 🎯 Bean Validation
为什么要校验？

用户的输入永远是不可信的。

  • 必填字段没传
  • 邮箱格式错
  • 字符串超长
  • 年龄负数

这些必须在进入业务逻辑之前就拦住，否则会产生脏数据甚至崩溃。

本节目标

  • 掌握 JSR-380 常用注解
  • 会用 @Valid 触发校验
  • 处理校验失败异常

1. 引入依赖

<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-validation</artifactId>
</dependency>

2. 常用注解

注解作用示例
@NotNull不能为 null@NotNull Long id
@NotEmpty不能为空（集合/字符串）@NotEmpty List<?> list
@NotBlank不能为空且非纯空格@NotBlank String name
@Email邮箱格式@Email String email
@Size(min, max)长度@Size(max=100) String name
@Min/@Max数值范围@Min(0) int age
@Pattern正则@Pattern(regexp = "^1\\d{10}$") String phone
@Past/@Future过去/未来时间@Past LocalDate birthday

3. DTO 上加注解

public record CreateUserRequest(
    @NotBlank(message = "用户名不能为空")
    @Size(min = 3, max = 20, message = "用户名长度 3-20")
    String username,

    @NotBlank @Email(message = "邮箱格式错误")
    String email,

    @NotNull @Min(0) @Max(150)
    Integer age,

    @Size(max = 200)
    String bio
) {}

4. Controller 触发校验

@PostMapping("/users")
public ApiResponse<User> create(@RequestBody @Valid CreateUserRequest req) {
  // @Valid 触发校验，失败抛 MethodArgumentNotValidException
  return ApiResponse.success(userService.create(req));
}

@PutMapping("/users/{id}")
public ApiResponse<User> update(
    @PathVariable Long id,
    @RequestBody @Valid UpdateUserRequest req
) {
  return ApiResponse.success(userService.update(id, req));
}

// 单个参数校验（@PathVariable / @RequestParam）
@GetMapping("/users/{id}")
public ApiResponse<User> get(
    @PathVariable @Min(1) Long id  // 也要加 @Validated
) { ... }

对 @PathVariable 和 @RequestParam 校验，需要在类上加 @Validated。

5. 统一处理校验失败

@RestControllerAdvice
public class GlobalExceptionHandler {

  @ExceptionHandler(MethodArgumentNotValidException.class)
  public ApiResponse<Map<String, String>> handleValidation(
      MethodArgumentNotValidException e
  ) {
    Map<String, String> errors = new HashMap<>();
    e.getBindingResult().getFieldErrors().forEach(fe ->
      errors.put(fe.getField(), fe.getDefaultMessage())
    );
    return ApiResponse.error(400, "参数校验失败").data(errors);
    // {
    //   "code": 400,
    //   "message": "参数校验失败",
    //   "data": { "email": "邮箱格式错误", "age": "必须大于等于 0" }
    // }
  }
}

6. 分组校验

不同场景用不同规则：

public interface CreateGroup {}
public interface UpdateGroup {}

public class UserDTO {
  @Null(groups = CreateGroup.class, message = "创建时 id 必须为空")
  @NotNull(groups = UpdateGroup.class, message = "更新时 id 不能为空")
  private Long id;

  @NotBlank(groups = {CreateGroup.class, UpdateGroup.class})
  private String name;
}

// 使用
@PostMapping
public User create(@RequestBody @Validated(CreateGroup.class) UserDTO dto) { ... }

@PutMapping
public User update(@RequestBody @Validated(UpdateGroup.class) UserDTO dto) { ... }
