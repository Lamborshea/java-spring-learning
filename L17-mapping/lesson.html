L17 实体关系映射

本节目标

  • 掌握 @OneToOne / @OneToMany / @ManyToOne / @ManyToMany
  • 理解 LAZY / EAGER 加载
  • 避免 N+1 查询问题

1. 关系速查

关系示例注解
一对一用户 ↔ 身份证@OneToOne
一对多用户 → 多篇文章@OneToMany + @ManyToOne
多对一多篇文章 → 一个作者@ManyToOne
多对多学生 ↔ 课程@ManyToMany

2. @ManyToOne（最常用）

@Entity
public class Article {
  @Id
  @GeneratedValue(strategy = GenerationType.IDENTITY)
  private Long id;

  private String title;
  private String content;

  // 多篇文章对应一个作者
  @ManyToOne(fetch = FetchType.LAZY)  // 推荐 LAZY
  @JoinColumn(name = "author_id")    // 外键列名
  private User author;
}

3. @OneToMany

@Entity
public class User {
  @Id
  @GeneratedValue(strategy = GenerationType.IDENTITY)
  private Long id;

  private String name;

  // 一个用户有多篇文章
  @OneToMany(
    mappedBy = "author",          // 由 Article.author 维护
    cascade = CascadeType.ALL,    // 级联操作
    orphanRemoval = true          // 孤儿删除
  )
  private List<Article> articles = new ArrayList<>();
}
双向关系的"主导方"

谁有外键谁是主导方。在 @OneToMany 中：

  • Article.author 有外键 → 它是主导方
  • User.articles 用 mappedBy = "author" 表示"反方"
  • 反方不能独立插入（必须通过主导方）

4. @OneToOne

@Entity
public class User {
  @Id
  private Long id;

  @OneToOne(fetch = FetchType.LAZY)
  @JoinColumn(name = "profile_id")
  private UserProfile profile;
}

@Entity
public class UserProfile {
  @Id
  private Long id;
  private String bio;
}

5. @ManyToMany

@Entity
public class Student {
  @Id
  private Long id;
  private String name;

  @ManyToMany
  @JoinTable(
    name = "student_course",
    joinColumns = @JoinColumn(name = "student_id"),
    inverseJoinColumns = @JoinColumn(name = "course_id")
  )
  private Set<Course> courses = new HashSet<>();
}

@Entity
public class Course {
  @Id
  private Long id;
  private String name;

  @ManyToMany(mappedBy = "courses")
  private Set<Student> students = new HashSet<>();
}

6. 加载策略

策略说明何时用
LAZY（推荐）访问时才查询@OneToMany、@ManyToMany
EAGER立即加载@OneToOne、@ManyToOne（可选）

7. N+1 问题

这是性能最常见的坑。看代码：

// ❌ 触发 N+1：1 次查用户 + N 次查文章
List<User> users = userRepository.findAll();
for (User u : users) {
  System.out.println(u.getArticles().size());  // 每条都查一次
}

// ✅ 解决 1：JOIN FETCH
@Query("SELECT DISTINCT u FROM User u LEFT JOIN FETCH u.articles")
List<User> findAllWithArticles();

// ✅ 解决 2：@EntityGraph
@EntityGraph(attributePaths = "articles")
List<User> findAll();
