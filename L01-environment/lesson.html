L01 开发环境搭建

⏱ 2 小时 📦 Java 基础 🎯 环境准备

本节目标

  • 安装 JDK 17（Java 开发工具包）
  • 安装 Maven（Java 的包管理工具，类似 npm）
  • 配置 IDE（IntelliJ IDEA 推荐）
  • 成功跑通第一个 Java 程序

你需要装什么？

工具类比前端作用
JDK 17Node.js 运行时编译和运行 Java 程序
Mavennpm / yarn依赖管理和构建
IntelliJ IDEAVS Code / WebStorm写代码的 IDE

Mac 安装（推荐 Homebrew）

# 1. 装 JDK 17
brew install openjdk@17

# 2. 装 Maven
brew install maven

# 3. 配置环境变量（添加到 ~/.zshrc）
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
export PATH=$JAVA_HOME/bin:$PATH

# 4. 生效
source ~/.zshrc

# 5. 验证
java -version
mvn -version

Windows 安装

# 1. 装 JDK
winget install Oracle.JDK.17

# 2. 装 Maven
# 下载 https://maven.apache.org/download.cgi
# 解压到 C:\apache-maven-3.9.x

# 3. 配置环境变量（系统属性 → 高级 → 环境变量）
# JAVA_HOME = C:\Program Files\Java\jdk-17
# MAVEN_HOME = C:\apache-maven-3.9.x
# Path 中加 %JAVA_HOME%\bin 和 %MAVEN_HOME%\bin

# 4. 验证
java -version
mvn -version

IDE 安装

# Mac
brew install --cask intellij-idea

# Windows
winget install JetBrains.IntelliJIDEA.Community

用 IDEA 打开整个 java-spring-learning 根目录即可，Maven 项目会被自动识别。

跑通第一个程序

cd L01-environment
mvn compile exec:java -Dexec.mainClass="com.learning.l01.HelloWorld"

看到 Hello, World! 即成功。

常见卡点

问题 1：Maven 依赖下载极慢

解决：配置阿里云镜像。修改 ~/.m2/settings.xml：

<mirrors>
  <mirror>
    <id>aliyun</id>
    <mirrorOf>*</mirrorOf>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>

问题 2：IDEA 找不到 JDK

解决：File → Project Structure → SDKs → + → Add JDK → 选 JDK 安装目录

问题 3：java 命令找不到

解决：检查 JAVA_HOME 是否配置正确，重启终端

项目结构理解

L01-environment/
├── pom.xml                  ← 类似 package.json
└── src/
    └── main/
        └── java/
            └── com/
                └── learning/
                    └── l01/
                        └── HelloWorld.java   ← 主类，必须与文件名一致

前端Java
package.jsonpom.xml
node_modules/本地仓库 ~/.m2/repository/
src/src/main/java/
