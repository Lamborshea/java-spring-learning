L18 事务管理

⏱ 2 小时 📦 数据访问 🎯 @Transactional
什么是事务？

一组数据库操作，要么全部成功，要么全部失败。
典型场景：转账（A 减 100，B 加 100），不能 A 减了 B 没加。

本节目标

  • 理解 ACID 特性
  • 会用 @Transactional
  • 理解传播行为和隔离级别

1. ACID 四大特性

特性含义JS 类比
Atomic 原子性全部成功或全部回滚Promise.all 要么全成功要么全失败
Consistency 一致性数据约束不变数据库约束
Isolation 隔离性并发事务互不干扰数据库锁
Durability 持久性提交后永久保存写入磁盘

2. @Transactional 基础

@Service
public class TransferService {

  @Autowired
  private AccountRepository accountRepo;

  @Transactional   // ← 这一行就够了
  public void transfer(Long fromId, Long toId, BigDecimal amount) {
    Account from = accountRepo.findById(fromId).orElseThrow();
    Account to = accountRepo.findById(toId).orElseThrow();

    from.setBalance(from.getBalance().subtract(amount));
    to.setBalance(to.getBalance().add(amount));

    accountRepo.save(from);
    accountRepo.save(to);
    // 任何一步抛异常，全部回滚
  }
}

3. 传播行为（Propagation）

事务方法 A 调用事务方法 B，怎么处理？

行为说明使用场景
REQUIRED（默认）有事务则加入，没有则新建大多数
REQUIRES_NEW总是新建，挂起外层独立日志/审计
NESTED嵌套（Savepoint）局部回滚
SUPPORTS有则加入，无则无事务查询
NOT_SUPPORTED非事务执行统计
MANDATORY必须在事务中，否则抛异常核心业务
NEVER必须不在事务中只读
 
@Service
public class OrderService {
  @Autowired
  private AuditService auditService;

  @Transactional
  public void createOrder() {
    orderRepository.save(new Order());
    // 主业务事务
    auditService.log("订单创建");
    // 审计失败不应回滚主业务
  }
}

@Service
public class AuditService {
  @Transactional(propagation = Propagation.REQUIRES_NEW)
  public void log(String message) {
    auditRepository.save(new AuditLog(message));
    // 独立事务，外层失败不影响
  }
}

4. 隔离级别（Isolation）

级别脏读不可重复读幻读性能
READ_UNCOMMITTED✓✓✓最高
READ_COMMITTED✗✓✓中等
REPEATABLE_READ（MySQL 默认）✗✗✓较低
SERIALIZABLE✗✗✗最低
 
@Transactional(isolation = Isolation.READ_COMMITTED)
public void someMethod() { ... }

5. 回滚规则

默认行为：

  • RuntimeException 及其子类 → 回滚
  • checked Exception → 不回滚
@Transactional(
  rollbackFor = Exception.class,           // 任何异常都回滚
  noRollbackFor = BusinessWarning.class   // 业务警告不回滚
)
public void method() { ... }

6. 实战演示：转账

@Service
public class TransferService {
  @Autowired
  private AccountRepository accountRepo;

  @Transactional
  public void transfer(Long fromId, Long toId, BigDecimal amount) {
    Account from = accountRepo.findById(fromId)
        .orElseThrow(() -> new BusinessException(404, "转出账户不存在"));
    Account to = accountRepo.findById(toId)
        .orElseThrow(() -> new BusinessException(404, "转入账户不存在"));

    if (from.getBalance().compareTo(amount) < 0) {
      throw new BusinessException(400, "余额不足");
    }

    from.setBalance(from.getBalance().subtract(amount));
    to.setBalance(to.setBalance(to.getBalance().add(amount)));
    // 如果 to.setBalance 写错了抛异常，整个 transfer 回滚
  }
}

7. 常见坑

⚠️ @Transactional 失效场景
  1. 方法不是 public：Spring 不会代理非 public 方法
  2. 同类方法调用：this.method() 绕过代理
  3. 异常被 catch 了：try-catch 后没抛出，事务管理器看不到异常
  4. 抛 checked exception：默认不回滚，要 rollbackFor = Exception.class
  5. 数据库不支持：MyISAM 不支持事务，要用 InnoDB
