L09 日志实战

⏱ 1.5 小时 📦 Spring Boot 核心 🎯 SLF4J + Logback

本节目标

  • 掌握 SLF4J 日志 API
  • 配置日志级别和格式
  • 理解日志占位符 {}
  • 日志输出到文件

1. 五个日志级别

级别用途是否输出
TRACE最详细，框架级仅调试时
DEBUG调试信息开发环境
INFO一般信息（推荐）生产默认
WARN警告需要注意
ERROR错误必须处理

2. 使用 SLF4J 记录日志

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

@Service
public class UserService {
  private static final Logger log = LoggerFactory.getLogger(UserService.class);

  public void createUser(String name) {
    log.info("创建用户: {}", name);
    log.debug("详细信息: name={}, time={}", name, LocalDateTime.now());
    log.warn("警告：用户名为空");
    log.error("错误：保存失败", new RuntimeException("DB error"));
  }
}

3. 占位符 vs 字符串拼接

这是性能关键点。看代码：

反例（不要这样） 
// 即使不输出，拼接也会执行
log.debug("用户信息: " + user);
正例（推荐） 
// 占位符 {}，未启用级别不执行
log.debug("用户信息: {}", user);

在生产环境，DEBUG 通常关闭。"a" + b + c 仍然会执行字符串拼接（消耗 CPU），而 "{}" 不会。

4. 配置日志（application.yml）

logging:
  level:
    root: INFO                        # 全局默认级别
    com.learning: DEBUG               # 自己的包用 DEBUG
    org.springframework.web: INFO     # Spring 框架保持 INFO
  pattern:
    console: "%d{HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n"

  file:
    name: logs/app.log                # 输出到文件
    max-size: 10MB                    # 单文件大小
    max-history: 30                   # 保留 30 天

5. Lombok 简化（推荐）

@Service
@Slf4j  // 自动生成：private static final Logger log = LoggerFactory.getLogger(...);
public class UserService {
  public void createUser(String name) {
    log.info("创建用户: {}", name);
  }
}
生产建议
  • 用 log.info 记录关键业务节点（订单创建、用户登录）
  • 用 log.error + 完整异常堆栈
  • 不要用 System.out.println（生产环境无法关闭）
