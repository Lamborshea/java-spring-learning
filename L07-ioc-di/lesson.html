L07 IoC 容器与依赖注入

⏱ 2 小时 📦 Spring Boot 核心 🎯 Spring 的灵魂
Spring 的灵魂
IoC 和 DI 是 Spring 最核心的设计思想。不理解这个，后面所有内容都会别扭。

本节目标

  • 理解 IoC（控制反转）是什么
  • 掌握 DI（依赖注入）三种方式
  • 会用 @Component / @Service / @Repository
  • 理解 Bean 作用域

1. 没有 IoC 之前

JavaScript 
// 传统方式：自己 new
class UserService {
  constructor() {
    this.userRepository = new UserRepository();
    // 紧耦合：换实现要改源码
  }
}
Java (传统) 
// 自己 new
public class UserService {
  private UserRepository userRepository =
      new UserRepository();
  // 紧耦合：要换实现必须改源码
}

2. IoC 方式：容器帮你创建

IoC = Inversion of Control（控制反转）

"控制权"从你手里反转到了 Spring 容器。对象由容器创建，依赖由容器注入。

JavaScript 
// 类比 Vue 的 provide/inject
// 或 React Context
const UserContext = createContext();

// 父组件 provide
provide('userService', new UserService());

// 子组件 inject
const userService = inject('userService');
Java (Spring) 
@Service
public class UserService {
  private final UserRepository userRepository;

  // 容器自动注入，不需要 new
  public UserService(UserRepository userRepository) {
    this.userRepository = userRepository;
  }
}
IoC 的本质

不要问"我该 new 谁"，问"我需要谁，Spring 会给我"。

类似餐厅：你点菜，服务员（容器）把菜（Bean）端给你，而不是你自己下厨。

3. 三种注入方式

方式推荐度代码
构造方法注入⭐⭐⭐⭐⭐通过构造函数
Setter 注入⭐⭐⭐通过 setter 方法
字段注入⭐（不推荐）直接在字段上加 @Autowired
 
// 1️⃣ 构造方法注入（推荐）
@Service
public class UserService {
  private final UserRepository userRepository;

  public UserService(UserRepository userRepository) {
    this.userRepository = userRepository;
  }
}

// 用 Lombok 简化
@Service
@RequiredArgsConstructor  // 自动生成包含 final 字段的构造
public class UserService {
  private final UserRepository userRepository;
  // 不用手写构造方法
}

// 2️⃣ Setter 注入
@Service
public class UserService {
  private UserRepository userRepository;

  @Autowired
  public void setUserRepository(UserRepository r) {
    this.userRepository = r;
  }
}

// 3️⃣ 字段注入（不推荐，测试困难）
@Service
public class UserService {
  @Autowired
  private UserRepository userRepository;  // 直接注入字段
}

4. 三个核心注解

它们都是 @Component 的"特化"，作用一样，名字不同，方便分类：

注解用途层级
@Component通用组件通用
@Service业务逻辑层Service
@Repository数据访问层Repository / DAO
@Controller控制器（Web）Controller
@RestControllerREST 控制器Controller
@Configuration配置类配置

5. Bean 作用域

Bean 作用域 = 容器怎么创建 Bean 实例。

作用域说明使用场景
singleton（默认）整个应用只有一个实例无状态服务（最常用）
prototype每次 getBean() 都创建新实例有状态对象
request每个 HTTP 请求一个实例Web 请求作用域
session每个 HTTP 会话一个实例用户会话数据
 
@Configuration
public class AppConfig {

  @Bean  // 默认 singleton
  public EmailService emailService() {
    return new EmailService();
  }

  @Bean
  @Scope("prototype")  // 每次都新创建
  public ReportGenerator reportGenerator() {
    return new ReportGenerator();
  }
}
