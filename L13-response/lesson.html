L13 响应统一封装

⏱ 1.5 小时 📦 Web 开发 🎯 ApiResponse 设计
为什么要统一封装？

如果没有统一格式，前端要面对各种"奇形怪状"的响应：

  • 成功时返回 {data: ...}
  • 失败时返回 {error: "..."}
  • 异常时直接 500 + HTML

前端每次都要写 if (res.success) ...，难维护。

本节目标

  • 设计统一的 ApiResponse<T>
  • 处理分页响应
  • 用 ResponseEntity 控制状态码

1. 设计响应格式

业界通用格式：

{
  "code": 200,
  "message": "success",
  "data": { ... },
  "timestamp": "2024-01-01T12:00:00"
}
  • code：业务状态码（200 成功、400 参数错、500 服务异常）
  • message：人类可读消息
  • data：真正的数据
  • timestamp：可选，时间戳

2. 实现 ApiResponse

@Data
public class ApiResponse<T> {
  private int code;
  private String message;
  private T data;
  private long timestamp = System.currentTimeMillis();

  public static <T> ApiResponse<T> success(T data) {
    ApiResponse<T> r = new ApiResponse<>();
    r.code = 200;
    r.message = "success";
    r.data = data;
    return r;
  }

  public static <T> ApiResponse<T> error(int code, String message) {
    ApiResponse<T> r = new ApiResponse<>();
    r.code = code;
    r.message = message;
    return r;
  }
}

// 使用
@GetMapping("/users/{id}")
public ApiResponse<User> get(@PathVariable Long id) {
  User user = userService.findById(id);
  return ApiResponse.success(user);
}

3. 分页响应

@Data
public class PageResponse<T> {
  private List<T> content;
  private int page;
  private int size;
  private long total;
  private int totalPages;
}

// 返回
@GetMapping("/users")
public ApiResponse<PageResponse<User>> list(
    @RequestParam(defaultValue = "0") int page,
    @RequestParam(defaultValue = "10") int size
) {
  Page<User> p = userService.findPage(page, size);
  PageResponse<User> pr = new PageResponse<>();
  pr.setContent(p.getContent());
  pr.setPage(page);
  pr.setSize(size);
  pr.setTotal(p.getTotalElements());
  pr.setTotalPages(p.getTotalPages());
  return ApiResponse.success(pr);
}

4. ResponseEntity 精细控制

// 完整控制：状态码 + 头 + 体
@PostMapping("/users")
public ResponseEntity<ApiResponse<User>> create(
    @RequestBody @Valid CreateUserRequest req
) {
  User user = userService.create(req);
  URI location = URI.create("/api/users/" + user.getId());

  return ResponseEntity
      .status(HttpStatus.CREATED)        // 201
      .header("X-User-Id", user.getId().toString())
      .location(location)                // Location header
      .body(ApiResponse.success(user));
}

// 204 No Content
@DeleteMapping("/users/{id}")
public ResponseEntity<Void> delete(@PathVariable Long id) {
  userService.delete(id);
  return ResponseEntity.noContent().build();  // 204
}

5. 错误码设计

public enum ErrorCode {
  SUCCESS(200, "成功"),
  PARAM_ERROR(400, "参数错误"),
  UNAUTHORIZED(401, "未登录"),
  FORBIDDEN(403, "无权限"),
  NOT_FOUND(404, "资源不存在"),
  CONFLICT(409, "冲突"),
  SERVER_ERROR(500, "服务器异常");

  public final int code;
  public final String message;
  ErrorCode(int code, String message) { this.code = code; this.message = message; }
}

// 使用
return ApiResponse.error(ErrorCode.NOT_FOUND.code, ErrorCode.NOT_FOUND.message);
