L16 Spring Data JPA 入门

⏱ 2 小时 📦 数据访问 🎯 ORM + Repository
JPA 是什么？

JPA = Java Persistence API，是 Java 的 ORM 规范。
Hibernate 是 JPA 最流行的实现。
Spring Data JPA 是 Spring 对 JPA 的封装，让数据库操作更简单。

类比：JPA 像 TypeScript 类型系统，Hibernate 像编译器，Spring Data JPA 像 VS Code 给你自动补全。

本节目标

  • 理解 JPA / Hibernate / Spring Data JPA 关系
  • 会用 @Entity 定义实体
  • 会用 JpaRepository 做 CRUD
  • 会用方法名派生查询

2. 定义 Entity

@Entity                    // 标记为 JPA 实体
@Table(name = "users")     // 对应表名（默认是类名）
@Data
@NoArgsConstructor
public class User {
  @Id                       // 主键
  @GeneratedValue(strategy = GenerationType.IDENTITY)
  private Long id;

  @Column(nullable = false, unique = true, length = 50)
  private String username;

  @Column(nullable = false)
  private String email;

  private Integer age;

  @CreationTimestamp        // 创建时自动填充
  private LocalDateTime createdAt;

  @UpdateTimestamp          // 更新时自动填充
  private LocalDateTime updatedAt;
}
注解作用
@Entity标记实体类
@Table指定表名
@Id主键
@GeneratedValue主键生成策略
@Column字段约束
@CreationTimestamp创建时间自动填充

3. Repository 接口

public interface UserRepository extends JpaRepository<User, Long> {
  // 啥都不写，已经有 20+ 个方法了
}

继承的层次：

Repository
  └── CrudRepository           # save, findById, findAll, delete, count
      └── PagingAndSortingRepository  # + 分页和排序
          └── JpaRepository   # + 批量操作、刷新等

开箱即用的方法：

userRepository.save(user);                // 插入或更新
userRepository.saveAll(list);
userRepository.findById(1L);              // Optional<User>
userRepository.findAll();                 // List<User>
userRepository.findAll(PageRequest.of(0, 10));  // 分页
userRepository.existsById(1L);
userRepository.count();
userRepository.deleteById(1L);
userRepository.delete(user);

4. 方法名派生查询（黑魔法）

Spring Data JPA 能从方法名自动生成 SQL：

public interface UserRepository extends JpaRepository<User, Long> {
  // WHERE username = ?
  Optional<User> findByUsername(String username);

  // WHERE age > ?
  List<User> findByAgeGreaterThan(Integer age);

  // WHERE name LIKE '%?%'
  List<User> findByNameContaining(String keyword);

  // WHERE age BETWEEN ? AND ?
  List<User> findByAgeBetween(Integer min, Integer max);

  // WHERE email = ? AND username = ?
  Optional<User> findByEmailAndUsername(String email, String username);

  // ORDER BY age DESC
  List<User> findByOrderByAgeDesc();

  // LIMIT 1
  Optional<User> findFirstByOrderByAgeDesc();
}

关键字：findBy、countBy、deleteBy、existsBy，配合 And、Or、Like、Containing、Between、GreaterThan、OrderBy...

5. @Query 自定义查询

复杂查询用 @Query：

public interface UserRepository extends JpaRepository<User, Long> {

  @Query("SELECT u FROM User u WHERE u.email LIKE %:domain%")
  List<User> findByEmailDomain(@Param("domain") String domain);

  @Query("SELECT u FROM User u WHERE u.age >= :minAge ORDER BY u.age ASC")
  List<User> findAdults(@Param("minAge") int minAge);

  // 原生 SQL
  @Query(value = "SELECT * FROM users WHERE age > ?1", nativeQuery = true)
  List<User> findByAgeGreaterThanSql(int age);

  // 更新
  @Modifying
  @Query("UPDATE User u SET u.email = :email WHERE u.id = :id")
  int updateEmail(@Param("id") Long id, @Param("email") String email);
}
